The non-canvas way to read the architecture — a peer of the map, not a debug table.

```jsx
<ArchitectureTree items={tree} expanded={open} onToggle={toggle} onActivate={enter} />
```

The Origin column is mandatory: it is how a screen-reader or keyboard user gets the same layer signal a sighted user gets from icon and shape. An AI-named row keeps its neutral label after the attributed prefix.
