Shows which analysis run the screen is describing.

```jsx
<RunPicker runId="run:1f7f34f034dc4674a8f395f29adb58ee" lastScanned="scanned 4m ago" freshness="Live" />
```

Human freshness leads; the raw id stays available but abbreviated and de-emphasised (mono, 10.5px, 75% opacity) with a copy action. Never make the raw id the loudest text on a screen.
