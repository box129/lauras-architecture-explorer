# 3. Landing page

**Not marketing. Step one of the workflow.**

## Layout

```
Laura's                                   [theme] [Settings]

Understand an unfamiliar codebase.
Laura's reads a repository on your machine, maps how it is put
together, and keeps every architectural statement attached to the
exact source that supports it.

[ Browse repository ]   Source analysis runs entirely without AI.
                        A model is optional, and only ever adds
                        interpretation on top.

Architecture        Explore              Verify
…                   …                    …

Recent projects
  topic-similarity-mvp   ~/code/…        51 modules · 6 minutes ago
  flask                  ~/code/flask    267 modules · yesterday

─────────────────────────────────────────────────────────────
STRUCTURE  CLUSTER  VERIFIED          AI INTERPRETATION
Always available. Deterministic,      Optional, always something
never calls a model.                  you ask for.
```

## Rules

- One primary action, 48px, icon-led: **Browse repository**. Nothing competes.
- The AI answer is given before it is asked, in one sentence next to the button.
- The provenance strip at the bottom teaches the product's core distinction in
  four chips before the user ever sees a map — the same chips they will meet
  inside.
- Recent projects appear only when real history exists; no empty shell.
- Settings is a text-level action in the header. No environment form, no wizard.
- **Analysis state replaces the lower half in place** — no page transition.
  Human stage copy, a real file counter, and one sentence on what happens next.
  Never a bare spinner and never a fake percentage.

## Copy

Title: *Understand an unfamiliar codebase.*
Never "AI-powered", never "instantly", never an exclamation mark.
