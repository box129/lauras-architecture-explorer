# 8. Contextual panel

One frame, four contents, always about what is on screen.

| State | Eyebrow / title | Body |
|---|---|---|
| **Overview** | Repository / repo name | real counts; "Where to start" naming the densest section with a direct action; README orientation **collapsed** into a `<details>` at the bottom |
| **Group** | Structural cluster or Repository section / its name | AI slot; facts (modules, internal relations, origin); "Why these modules are grouped" edge triples; member list |
| **Entity** | Module / file name | where it sits (section, cluster, in/out degree); statement tally by verdict; architectural-explanation state |
| **Evidence** | Statement / the statement text | verdict, relation, evidence count; context line; "Back to the module" |

## Rules

- Repo-wide orientation content is never the default panel again. It is not
  deleted — it is one collapsed section at the one state where it is relevant.
- Panel width 348px; collapses below 1280px (see RESPONSIVE_SPEC).
- Every number in the panel is a real computed count.
