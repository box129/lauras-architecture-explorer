# Laura's architecture-first graph prototype

Open `index.html` in the Claude Design preview environment.

The default state is Dark Mode with optional AI labels ON so the prototype
shows the intended final architecture-reading experience. Use the toolbar to
switch AI labels off and confirm the same deterministic geometry and relation
counts remain.

## Design intent

The primary map should read as software architecture before it reads as a
filesystem:

- large deterministic `Backend` / `Frontend` structural frames;
- relation-oriented areas such as the deterministic `controllers` and
  `services` sections positioned by connectivity;
- deterministic structural clusters inside the service area;
- real aggregated relation arrows;
- paths shown as secondary structural basis;
- optional iris-labelled AI names layered over fixed membership.

See `../../design-package/19_ARCHITECTURE_GRAPH_SPEC.md` and
`../../design-package/20_ARCHITECTURE_FIRST_RECOMPOSITION.md`.

The screenshot in `../../reference/architecture-first-target.png` is a visual
north-star only. Its semantic labels are illustrative and are not source-code
truth.
