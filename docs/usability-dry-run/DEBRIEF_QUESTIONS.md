# Debrief questions

Ask after all tasks are complete, before stopping the recording. Keep
this separate from the formal A/B/C study questionnaire — this is a
lightweight, non-scored conversation, not an instrument.

1. What did you think **SUPPORTED** meant, when you first saw it?
2. What did **INSUFFICIENT EVIDENCE** mean to you? (Only ask if they saw
   one during the session.)
3. Did you trust the explanation Laura's gave you? Why or why not?
4. Could you tell which information came from real source code, versus
   which part (if any) felt like it was just the AI talking?
5. Was anything difficult to find?
6. What would you change first, if you could change one thing?
7. Could you imagine using this on a codebase you don't already know?
   What for?
8. Was there anything you expected the tool to do that it didn't?
9. Anything else you want to say that we didn't ask about?

Thank them. Don't promise specific changes will follow from this
session — it's exploratory input, not a commitment.
